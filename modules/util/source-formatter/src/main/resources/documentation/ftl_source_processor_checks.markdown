# Checks for .ftl

Check | Category | Description
----- | -------- | -----------
FTLEmptyLinesCheck | Styling | Finds missing and unnecessary empty lines. |
FTLIfStatementCheck | Styling | Finds incorrect use of parentheses in statement. |
FTLImportsCheck | Styling | Sorts and groups imports in `.ftl` files. |
FTLLiferayVariableOrderCheck | Styling | Sorts assign statement of `liferay_*` variables. |
FTLStringRelationalOperatorCheck | Styling | Finds cases of `==` or `!=` where `stringUtil.equals`, `validator.isNotNull` or `validator.isNull` can be used instead. |
FTLStylingCheck | Styling | Applies rules to enforce consisteny in code style. |
FTLTagAttributesCheck | Styling | Sorts and formats attributes values in tags. |
FTLTagCheck | Styling | Finds cases where consecutive `#assign` can be combined. |
FTLWhitespaceCheck | Styling | Finds missing and unnecessary whitespace in `.ftl` files. |
