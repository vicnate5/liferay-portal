# Checks for .yaml or .yml

Check | Category | Description
----- | -------- | -----------
YMLDefinitionOrderCheck | Styling | Sorts definitions alphabetically in `.yml` files. |
YMLEmptyLinesCheck | Styling | Finds missing and unnecessary empty lines. |
YMLLongLinesCheck | Styling | Finds lines that are longer than the specified maximum line length. |
YMLStylingCheck | Styling | Applies rules to enforce consisteny in code style. |
YMLWhitespaceCheck | Styling | Finds missing and unnecessary whitespace in `.yml` files. |
