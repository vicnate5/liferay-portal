# Checks for .js or .jsx

Check | Category | Description
----- | -------- | -----------
[JSLodashDependencyCheck](checks/js_lodash_dependency_check.markdown#jslodashdependencycheck) | Bug Prevention | Finds incorrect use of `AUI._`. |
JSStylingCheck | Styling | Applies rules to enforce consisteny in code style. |
JSWhitespaceCheck | Styling | Finds missing and unnecessary whitespace in `.js` files. |
LanguageKeysCheck | Bug Prevention | Finds missing language keys in `Language.properties`. |
