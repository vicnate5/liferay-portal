# Checks for .tld

Check | Category | Description
----- | -------- | -----------
TLDElementOrderCheck | Styling | Checks the order of attributers in `.tld` file. |
TLDTypeCheck | Bug Prevention | Ensures the fully qualified name is used for types in `.tld` file. |
WhitespaceCheck | Styling | Finds missing and unnecessary whitespace. |
XMLIndentationCheck | Styling | Finds incorrect indentation in `.xml` files. |
