# Checks for .markdown or .md

Check | Category | Description
----- | -------- | -----------
MarkdownEmptyLinesCheck | Styling | Finds missing and unnecessary empty lines. |
MarkdownFileExtensionCheck | Styling | Finds `markdown` files with `.md` extension (use `.markdown`). |
MarkdownSourceFormatterDocumentationCheck | Documentation | Validates the header of Source Formatter documentation files. |
MarkdownSourceFormatterReadmeCheck | Documentation | Generates Source Formatter documentation index files. |
MarkdownStylingCheck | Styling | Applies rules to enforce consisteny in code style. |
MarkdownWhitespaceCheck | Styling | Finds missing and unnecessary whitespace in `.markdown` files. |
