# Checks for .css or .scss

Check | Category | Description
----- | -------- | -----------
CSSCommentsCheck | Styling | Validates comments in `.css` files. |
CSSImportsCheck | Styling | Sorts and groups imports in `.css` files. |
CSSPropertiesOrderCheck | Styling | Sorts properties in `.css` files. |
WhitespaceCheck | Styling | Finds missing and unnecessary whitespace. |
